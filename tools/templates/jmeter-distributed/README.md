# Enterprise Apache JMeter Distributed Load Testing Architecture

This directory provides a 1-click Dockerized distributed JMeter cluster for injecting high-concurrency loads (> 5,000–50,000 VUs) across multiple injection nodes.

---

## Architecture Overview

```
                      +-------------------+
                      |   jmeter-master   | (Controller)
                      +---------+---------+
                                | RMI (Non-SSL)
        +-----------------------+-----------------------+
        |                       |                       |
+-------v-------+       +-------v-------+       +-------v-------+
| jmeter-slave-1|       | jmeter-slave-2|       | jmeter-slave-3|
| (1,000 VUs)   |       | (1,000 VUs)   |       | (1,000 VUs)   |
+-------+-------+       +-------+-------+       +-------+-------+
        |                       |                       |
        +-----------------------+-----------------------+
                                |
                        [Target System]
```

---

## Quick Start (3 Steps)

### 1. Start the Cluster
```bash
docker-compose up -d
```

### 2. Run Distributed Headless Execution from Master
Copy your test plan (generated by Synapse-Hub `agent-qa generate-jmx`) into `./plans/perf_plan.jmx`, then trigger:
```bash
docker exec -it jmeter-master jmeter -n \
  -t /jmeter/plans/perf_plan.jmx \
  -R jmeter-slave-1,jmeter-slave-2,jmeter-slave-3 \
  -Dserver.rmi.ssl.disable=true \
  -l /jmeter/reports/distributed_results.jtl \
  -e -o /jmeter/reports/dashboard
```

### 3. Evaluate SLA with Synapse-Hub Quality Gate
```bash
agent-qa analyze-jtl ./reports/distributed_results.jtl --sla-p95 500 --max-error-rate 1.0
```

### 4. Teardown
```bash
docker-compose down -v
```
